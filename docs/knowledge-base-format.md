# Knowledge-base package format

A Version 1 export is a ZIP containing `manifest.json`, `documents.json`, `chunks.jsonl`, `vectors/index.npy`, `vectors/metadata.json`, `configuration.json`, and `README.txt`. The manifest format is `confidencial-rag-knowledge-base` version 1 and includes knowledge-base ID, counts, embedding model, and vector dimension. Secrets, credentials, token vaults, logs, and notebook outputs are not persisted.
